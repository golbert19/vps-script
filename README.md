## 🚀 Descripción General
**Golbert VPS Premium** es un script de administración de servidores VPS de nivel empresarial y Ultra-Premium, diseñado específicamente para optimizar conexiones VPN, proteger cuentas mediante bloqueo **HWID (Hardware ID)**, gestionar revendedores con sistema de créditos y ofrecer un panel web moderno con diseño Dark Mode.

---

## 💎 Características Principales
* **🛰️ Gestión Avanzada de SSH:** Creación de cuentas normales o bloqueadas por HWID, AutoKill de multilogins, límites de IP/Conexiones personalizables y banners HTML dinámicos.
* **🎮 UDP Custom (Puerto 2000):** Optimizado para juegos en línea (Free Fire, CODM) y videollamadas con ultra-baja latencia.
* **🚀 HCR Nativo (Manager Pro v1.5.2):** Multiplexor TCP avanzado en el puerto 8880 compatible con HTTP Custom.
* **🎮 BadVPN UDPGW:** Servidores estables en los puertos **7300** y **7200**.
* **🛡️ Xray Protocolos:** Soporte completo para VMess, VLESS y Trojan con certificados SSL automáticos.
* **🌐 Panel Web (Dashboard UI):** Interfaz gráfica ligera basada en Flask para monitorear recursos, estado de los usuarios y creación rápida de cuentas desde cualquier navegador.
* **🤖 Bot de Telegram:** Integrado con sistema de roles para administración y control de créditos para revendedores.
